# MINIMALIST | Marketing & Conteúdo

Site estático em HTML, CSS e JavaScript, pronto para publicar no GitHub Pages.

## Publicar no GitHub Pages
1. Crie um repositório no GitHub.
2. Envie `index.html` e `README.md` para a raiz do repositório.
3. Abra **Settings → Pages**.
4. Em **Build and deployment**, escolha **Deploy from a branch**.
5. Selecione a branch `main` e a pasta `/ (root)`, depois clique em **Save**.
6. Aguarde a publicação e abra o endereço indicado pelo GitHub Pages.

Observação: o site carrega Tailwind CSS, ícones e fontes de CDNs externos, então esses recursos precisam de conexão com a internet. Substitua os espaços reservados de imagens/logos pelo conteúdo final quando quiser.
